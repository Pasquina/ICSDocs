The contents of this Documentation was derived directly from the extensive README contained in the ICS Distribution Download. It was created as a learning exercise by me (Milan Vydareny) to fulfill a couple of objectives.

* Establish a reliable source of easily accessed information to support ongoing use of ICS in development activities.
* Enable a more user friendly graphic style that permits easy learning and adoption of ICS.
* Make some minor edits to the text to expand or clarify some topics that the current author found difficult to understand.
* Share with others as an encouragement to use this extremely powerful and versatile set of components, largely developed and created by **francois.piette@overbyte.be**, as well as other contributors.

Any mistakes in this current documentation effort are my own, and not attributable to the original text. Please feel free to comment using the link at the bottom of each page. Suggestions and criticisms are always welcome.
