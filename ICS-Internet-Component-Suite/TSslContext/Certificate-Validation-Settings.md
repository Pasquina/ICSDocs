### The **Trust** Settings

These properties control whether your application implicitly trusts the mail server or requires proof of its identity.

+------------------------------------------------------------------------+-----------------------+--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| Property                                                               | Setting               | Function                                                                                                                                                                                                                                                                                                                       |
+========================================================================+=======================+================================================================================================================================================================================================================================================================================================================================+
| SslVerifyPeer (Boolean)                                                | True                  | ICS causes OpenSSL to validate the mail server's certificate as valid and issued by a trusted authority.                                                                                                                                                                                                                       |
+------------------------------------------------------------------------+-----------------------+--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
|                                                                        | False                 | No validation is performed. Mail is delivered faster, but you risk **man in the middle** attacks.                                                                                                                                                                                                                              |
+------------------------------------------------------------------------+-----------------------+--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| UseSharedCAStore (Boolean)                                             | True                  | Directs OpenSSL to use its built-in, preloaded list of global root certificates (like DigiCert, Let's Encrypt). If the TSslHtmlSslCli application is running on a Windows machine with a properly configured certificate store, it will also include the contents of that store as part of the certificate verification chain. |
+------------------------------------------------------------------------+-----------------------+--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
|                                                                        | False                 | The settings for `SslCAFile` and `SslCAPath` will be used to obtain the certificates for peer verification.                                                                                                                                                                                                                    |
+------------------------------------------------------------------------+-----------------------+--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| SslCAFile / SslCAPath (String) Only used if UseSharedCAStore is False. | Specified             | Provides the explicit path and filename to a specific Certificate Authority bundle file, i.e. cacert.pem, or folder.                                                                                                                                                                                                           |
+------------------------------------------------------------------------+-----------------------+--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
|                                                                        | Not Specified / Empty | A specific path and filename is not available for peer verification.                                                                                                                                                                                                                                                           |
+------------------------------------------------------------------------+-----------------------+--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
